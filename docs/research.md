# Research Plan

## Primary Question

Can developmental learning produce increasingly complex internal representations and adaptive behavior when an artificial agent starts with limited task-specific knowledge?

## Secondary Questions

- Can persistent memory improve long-horizon behavior?
- Can an agent learn a stable body representation?
- Can prediction errors drive useful exploration?
- Can social interaction improve learning?
- Can symbol associations emerge from repeated grounded interaction?
- Can an agent maintain a useful representation of its own past and current state?

## Scientific Rule

Do not label an observed behavior as consciousness merely because it resembles human behavior.

Every consciousness-related claim should include:
- measurable operational definition
- baseline comparison
- ablation
- reproducible seed
- quantitative metric
- alternative explanation
